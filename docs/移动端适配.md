# 移动端适配说明

## 适配概述

会议室管理系统已完成移动端响应式适配，支持手机、平板等设备访问。

---

## 适配页面

✅ 首页仪表盘 (Dashboard)
✅ 登录页 (Login)
✅ 会议室列表 (Rooms)
✅ 预约记录 (Bookings)
✅ 今日预约 (Today Bookings)
✅ 物品列表 (Items)
✅ 借用记录 (Borrowings)
✅ 个人中心 (Profile)
✅ 布局组件 (Layout)

---

## 响应式断点

| 断点 | 屏幕宽度 | 适配策略 |
|------|---------|---------|
| 桌面端 | > 768px | 原始布局 |
| 平板端 | ≤ 768px | 单列布局，字体缩小 |
| 手机端 | ≤ 480px | 紧凑布局，进一步优化 |

---

## 主要适配内容

### 1. 首页仪表盘

**桌面端**:
- 统计卡片：3 列网格
- 会议室卡片：3 列网格
- 物品卡片：3 列网格

**平板端 (≤768px)**:
- 统计卡片：1 列垂直排列
- 会议室卡片：1 列垂直排列
- 物品卡片：1 列垂直排列
- 字体大小适当缩小

**手机端 (≤480px)**:
- 进一步缩小字体和图标
- 卡片内边距减小
- 按钮宽度 100%

---

### 2. 登录页

**适配特性**:
- 背景渐变保持
- 登录框最大宽度 400px
- 移动端输入框高度增加到 44px（便于触摸）
- 字体大小适配

---

### 3. 列表页面（会议室/物品/预约/借用）

**适配特性**:
- 筛选表单垂直排列
- 卡片/表格单列显示
- 表格字体缩小到 12px
- 按钮尺寸优化

---

### 4. 布局组件

**桌面端**:
- 左侧固定侧边栏
- 顶部系统名称
- 右侧用户信息

**移动端 (≤768px)**:
- 侧边栏变为顶部横向滚动菜单
- 菜单项横向排列，可左右滑动
- 隐藏用户信息区域
- 主内容区占满全屏

---

### 5. 表格优化

**移动端表格特性**:
- 字体缩小到 12px
- 单元格内边距减小
- 状态标签缩小
- 操作按钮缩小

## 移动端 Meta 标签

已在 `index.html` 中添加：

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no, viewport-fit=cover" />
<meta name="apple-mobile-web-app-capable" content="yes" />
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent" />
<meta name="format-detection" content="telephone=no" />
<meta name="theme-color" content="#409EFF" />
```

**说明**:
- `user-scalable=no` - 禁止用户缩放
- `viewport-fit=cover` - 适配 iPhone 刘海屏
- `apple-mobile-web-app-capable` - iOS 全屏模式
- `theme-color` - 浏览器主题色

## 触摸优化

### 按钮和交互元素
- 最小触摸区域：44x44px
- 输入框高度：40-44px
- 按钮高度：40-44px

### 横向滚动菜单
- `-webkit-overflow-scrolling: touch` - iOS 平滑滚动
- `white-space: nowrap` - 防止换行

## 测试建议

1. Chrome DevTools → Toggle Device Toolbar (Ctrl+Shift+M)
2. 选择预设设备或自定义尺寸

---

## 已知限制

1. **表格在超小屏幕**：部分列可能隐藏，建议横向滚动查看
2. **复杂表单**：移动端建议简化表单字段
3. **图片上传**：移动端需调用相机/相册 API
