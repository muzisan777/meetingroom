## 日志类型

### 1. action.log - 用户操作日志

**记录内容**:
- ✅ 用户登录（成功/失败）
- ✅ 创建预约
- ✅ 取消预约
- ✅ 删除预约

**示例**:
```
2026-03-13 23:40:00 - INFO - [用户 ID:1 | 用户名:admin | 姓名:管理员] - Login SUCCESS | IP: 127.0.0.1
2026-03-13 23:41:00 - INFO - [用户 ID:1 | 用户名:admin | 姓名:管理员] - Booking CREATE: ID=10 | Room: 会议室 A | Time: 2026-03-14 09:00:00 - 2026-03-14 10:00:00
2026-03-13 23:42:00 - INFO - [用户 ID:1 | 用户名:admin | 姓名:管理员] - Booking CANCEL: ID=10 | Room: 会议室 A | Time: 2026-03-14 09:00:00 - 2026-03-14 10:00:00
2026-03-13 23:43:00 - INFO - [用户 ID:1 | 用户名:admin | 姓名:管理员] - Booking DELETE: ID=10 | Room: 会议室 A | Time: 2026-03-14 09:00:00 - 2026-03-14 10:00:00
```

### 2. access.log - API 访问日志

**记录内容**:
- ✅ 请求方法（GET/POST/PUT/DELETE）
- ✅ 请求路径
- ✅ 响应状态码
- ✅ 请求耗时（毫秒）
- ✅ 客户端 IP

**示例**:
```
2026-03-13 23:40:00 - INFO - [用户 ID:1 | 用户名:admin | 姓名:管理员] - API: GET /api/bookings/today | Status: 200 | Duration: 12ms | IP: 127.0.0.1
2026-03-13 23:40:01 - INFO - [用户 ID:1 | 用户名:admin | 姓名:管理员] - API: POST /api/bookings | Status: 200 | Duration: 45ms | IP: 127.0.0.1
2026-03-13 23:40:02 - WARNING - [用户 ID:1 | 用户名:admin | 姓名:管理员] - API: PUT /api/bookings/999/cancel | Status: 400 | Duration: 8ms | IP: 127.0.0.1
```

### 3. error.log - 错误日志

**记录内容**:
- ✅ 错误类型
- ✅ 错误消息
- ✅ 堆栈跟踪
- ✅ 上下文信息

**示例**:
```
2026-03-13 23:40:00 - ERROR - [用户 ID:None | 用户名:user1 | 姓名:None] - Error: HTTPException | 用户名或密码错误
2026-03-13 23:41:00 - ERROR - [用户 ID:1 | 用户名:admin | 姓名:管理员] - Error: ValidationError | 预约时间冲突
Traceback:
  File "main.py", line 1050, in create_booking
    db.commit()
  ...
```

## 审计示例

### 查看某个用户的所有操作
```bash
# Linux/Mac
grep "用户 ID:1" logs/*.log

# Windows PowerShell
Select-String -Pattern "用户 ID:1" -Path logs/*.log
```

### 查看特定用户名的操作
```bash
# 查看 admin 的所有操作
grep "用户名:admin" logs/*.log
```

### 查看特定姓名的操作
```bash
# 查看 张三 的所有操作
grep "姓名:张三" logs/*.log
```

### 查看所有登录记录
```bash
grep "Login" logs/action.log
```

### 查看所有预约操作
```bash
grep "Booking" logs/action.log
```

### 查看所有错误
```bash
grep "ERROR" logs/error.log
```

### 查看登录失败记录
```bash
grep "Login FAILED" logs/action.log
```

### 查看特定时间的操作
```bash
# 查看 23:40 到 23:50 之间的操作
grep "2026-03-13 23:4" logs/action.log
```

## 日志字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| 用户 ID | 数据库中的用户 ID | 1, 2, 3 |
