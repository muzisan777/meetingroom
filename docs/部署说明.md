# 会议室预约系统 - 部署说明

## 项目结构
```
meeting-room-system/
├── backend/                  # 后端服务 (FastAPI)
│   ├── main.py              # 主应用 & API 路由
│   ├── database.py          # 数据库配置
│   ├── models.py            # SQLAlchemy 模型
│   ├── schemas.py           # Pydantic 模型
│   ├── auth.py              # JWT 认证
│   ├── logger.py            # 日志系统
│   └── requirements.txt     # Python 依赖
├── frontend/                 # 前端应用 (Vue 3)
│   └── src/
│       ├── views/           # 页面组件
│       ├── api/             # API 封装 (Axios)
│       ├── router/          # 路由配置
│       └── stores/          # 状态管理 (Pinia)
└── docs/                     # 文档
    ├── CHANGELOG.md         # 更新日志
    ├── LOGGING.md           # 日志系统说明
    └── GITEE_UPLOAD.md      # Gitee 上传指南
```

## 部署步骤

### 1. 后端部署

#### 1.1 安装依赖
```bash
cd backend/
pip install -r requirements.txt
```

#### 1.2 启动后端服务
```bash
# 开发模式
python main.py

# 生产模式 (使用 uvicorn)
uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4

# 或使用 gunicorn (如果安装了)
gunicorn main:app -w 4 -k uvicorn.workers.UvicornWorker --bind 0.0.0.0:8000
```

#### 1.3 配置环境变量 (可选)
```bash
export DATABASE_URL="sqlite:///./meeting_room.db"
export SECRET_KEY="your-secret-key-here"
export ACCESS_TOKEN_EXPIRE_MINUTES=1440
```

### 2. 前端部署

#### 2.1 安装依赖
```bash
cd frontend/
npm install
```

#### 2.2 启动前端服务
```bash
# 开发模式
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

#### 2.3 配置 API 代理
在 `vite.config.js` 中配置：
```javascript
export default {
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:8000',
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/api/, '')
      }
    }
  }
}
```

## Docker 部署 (可选)

### 1. 后端 Dockerfile
```dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY backend/requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY backend/ .

EXPOSE 8000

CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

### 2. 前端 Dockerfile
```dockerfile
FROM node:18-alpine as build

WORKDIR /app

COPY frontend/package*.json ./
RUN npm install

COPY frontend/ .
RUN npm run build

FROM nginx:alpine
COPY --from=build /app/dist /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

### 3. Docker Compose
```yaml
version: '3.8'

services:
  backend:
    build: ./backend
    ports:
      - "8000:8000"
    volumes:
      - ./backend/data:/app/data
    environment:
      - DATABASE_URL=sqlite:///./data/meeting_room.db

  frontend:
    build: ./frontend
    ports:
      - "80:80"
    depends_on:
      - backend
```

## Nginx 反向代理配置

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /path/to/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 代理
    location /api {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

## 故障排除

### 常见问题

#### 1. 端口被占用
```bash
# 检查端口占用
netstat -tulnp | grep :8000
netstat -tulnp | grep :5173

# 杀死占用进程
pkill -f "python.*main"
pkill -f "node.*vite"
```

#### 2. 依赖安装失败
```bash
# 使用国内镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 或者
npm install --registry https://registry.npmmirror.com
```

#### 3. 权限问题
```bash
# 确保有足够权限
chmod +x backend/main.py
chmod +x frontend/vite.config.js
```
