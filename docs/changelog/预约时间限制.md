### 1. 时间选择限制 - 不能选择过去的时间 ✅

**文件**: `frontend/src/views/Dashboard.vue`

**新增函数**:
- `disabledHours()` - 禁用今天当前小时之前的所有小时
- `disabledMinutes(selectedHour)` - 禁用今天当前小时内，当前分钟之前的时间

**逻辑**:
```javascript
// 禁用过去的小时
const disabledHours = () => {
  const now = new Date()
  const currentHour = now.getHours()
  const today = now.toDateString()
  
  // 如果选择的是今天，禁用 0 到 currentHour-1 的所有小时
  if (selectedDate === today) {
    return Array.from({ length: currentHour }, (_, i) => i)
  }
  return []
}

// 禁用过去的分钟（15 分钟间隔）
const disabledMinutes = (selectedHour) => {
  const now = new Date()
  const currentHour = now.getHours()
  const currentMinute = now.getMinutes()
  
  // 如果选择的是今天且是当前小时
  if (selectedDate === today && selectedHour === currentHour) {
    // 计算当前应该禁用的分钟（向上取整到 15 的倍数）
    const minMinute = Math.ceil(currentMinute / 15) * 15
    // 返回所有小于 minMinute 的 15 分钟间隔
    const disabledMins = []
    for (let i = 0; i < minMinute && i < 60; i += 15) {
      disabledMins.push(i)
    }
    return disabledMins
  }
  return []
}
```

## 功能说明

### 时间选择逻辑

1. **选择今天**:
   - 禁用当前小时之前的所有小时（例如现在是 14:30，禁用 0-13 点）
   - 如果选择当前小时，禁用当前分钟之前的 15 分钟间隔（例如现在是 14:32，禁用 0, 15, 30 分）
   - 可选时间：14:45, 15:00, 15:15, ...

2. **选择明天及以后**:
   - 不禁用任何小时
   - 可选所有 15 分钟间隔：0, 15, 30, 45

### 快捷选项

点击快捷按钮可快速选择：
- **15 分钟后**: 当前时间向上取整到下一个 15 分钟间隔
- **30 分钟后**: 当前时间 + 30 分钟（15 分钟间隔）
- **1 小时后**: 当前时间 + 1 小时（整点）

## 技术细节

```javascript
// 向上取整到 15 分钟的倍数
const minMinute = Math.ceil(currentMinute / 15) * 15
// 例如：32 分钟 → Math.ceil(32/15) * 15 = Math.ceil(2.13) * 15 = 3 * 15 = 45
```
