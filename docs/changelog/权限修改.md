# Dashboard 权限隔离修改说明

## 修改时间
2026-03-13 22:20

## 修改内容

### 1. 今日预约列表 - 移除权限隔离 ✅

**文件**: `frontend/src/views/Dashboard.vue`

**修改前**:
```javascript
// 管理员统计所有预约，普通用户统计自己的
const filteredBookings = userStore.isAdmin 
  ? bookingsRes 
  : bookingsRes.filter(b => b.user_id === userStore.userInfo?.id)
stats.value.todayBookings = filteredBookings.filter(b => b.status !== 'cancelled').length
```

**修改后**:
```javascript
// 今日预约显示所有用户的预约（不限制权限）
stats.value.todayBookings = bookingsRes.filter(b => b.status !== 'cancelled').length
```

**效果**:
- ✅ 普通用户和管理员都能看到今天的所有预约
- ✅ 今日预约统计卡片显示所有预约数量
- ✅ 今日预约列表表格显示所有预约记录

### 2. 会议室卡片中的今日预约 - 移除权限隔离 ✅

**文件**: `frontend/src/views/Dashboard.vue`

**修改前**:
```javascript
// 会议室今日预约（过滤已取消的）
const getRoomTodayBookings = (roomId) => {
  return allBookings.value
    .filter(b => {
      const bookingDate = dayjs(b.start_time).format('YYYY-MM-DD')
      const today = dayjs().format('YYYY-MM-DD')
      return bookingDate === today && b.room_id === roomId && b.status !== 'cancelled'
    })
    .sort((a, b) => dayjs(a.start_time).valueOf() - dayjs(b.start_time).valueOf())
}
```

**修改后**:
```javascript
// 会议室今日预约（过滤已取消的，显示所有用户的预约）
const getRoomTodayBookings = (roomId) => {
  return todayBookingsList.value
    .filter(b => b.room_id === roomId)
    .sort((a, b) => dayjs(a.start_time).valueOf() - dayjs(b.start_time).valueOf())
}
```

**效果**:
- ✅ 会议室卡片显示今天该会议室的所有预约（不限制权限）
- ✅ 普通用户可以看到其他人预约的会议室
- ✅ 显示所有预约的时间、事由、状态

### 3. 我的预约 - 保持权限隔离

## 技术实现

### 数据流
```
后端 API /api/bookings?start_date=xxx&end_date=xxx
    ↓
Dashboard.vue: fetchDashboardData()
    ↓
bookingsRes (今日所有预约)
    ↓
├─→ stats.todayBookings (统计)
├─→ todayBookingsList (计算属性，今日预约列表)
└─→ getRoomTodayBookings(roomId) (会议室今日预约)
```

### 关键修改点
1. 移除 `filteredBookings` 过滤逻辑
2. `getRoomTodayBookings` 改用 `todayBookingsList.value` 作为数据源
3. 添加调试日志便于排查问题
