## 修改内容

### 1. 分钟以 15 分钟为最小单位（0, 15, 30, 45）✅

**实现方式**: 通过 `disabledMinutes` 函数控制，只返回不在 `[0, 15, 30, 45]` 范围内的分钟

**代码**:
```javascript
const validMinutes = [0, 15, 30, 45]

const disabledStartMinutes = (selectedHour) => {
  // ... 其他逻辑
  
  // 返回所有不在 validMinutes 中的分钟
  return Array.from({ length: 60 }, (_, i) => i)
    .filter(m => !validMinutes.includes(m))
}
```

**实际效果**:
- 分钟选择器只显示：**00, 15, 30, 45**
- 其他分钟（01-14, 16-29, 31-44, 46-59）都被禁用（灰色）

### 2. 预定时间范围限制：8:30-19:00 ✅

**开放时间配置**:
```javascript
const OPEN_HOUR = 8
const OPEN_MINUTE = 30
const CLOSE_HOUR = 19
const CLOSE_MINUTE = 0
```

**小时限制**:
- **开始时间**: 可选 8-18 点（19 点后不能开始新预约）
- **结束时间**: 可选 9-19 点（最早 9 点结束，最晚 19 点）

**分钟限制**:
- **8 点**: 只允许 30 分（8:00 和 8:15 被禁用）
- **19 点**: 只允许 00 分（19:15, 19:30, 19:45 被禁用）
- **其他小时**: 允许 0, 15, 30, 45

### 3. 时间验证规则 ✅

**验证函数**:
```javascript
// 验证时间在 8:30-19:00 范围内
const validateTimeRange = (rule, value, callback) => {
  const [hours, minutes] = value.split(':').map(Number)
  const timeInMinutes = hours * 60 + minutes
  const openTime = 8 * 60 + 30  // 510 分钟
  const closeTime = 19 * 60 + 0  // 1140 分钟
  
  if (timeInMinutes < openTime || timeInMinutes > closeTime) {
    callback(new Error('预约时间必须在 8:30-19:00 之间'))
  } else {
    callback()
  }
}

// 验证结束时间大于开始时间
const validateEndTime = (rule, value, callback) => {
  if (!value || !bookingForm.value.startTime) {
    callback()
    return
  }
  
  const [startHours, startMinutes] = bookingForm.value.startTime.split(':').map(Number)
  const [endHours, endMinutes] = value.split(':').map(Number)
  
  const startTimeInMinutes = startHours * 60 + startMinutes
  const endTimeInMinutes = endHours * 60 + endMinutes
  
  if (endTimeInMinutes <= startTimeInMinutes) {
    callback(new Error('结束时间必须大于开始时间'))
  } else {
    callback()
  }
}
```

**表单验证规则**:
```javascript
rules: {
  startTime: [
    { required: true, message: '请选择开始时间', trigger: 'change' },
    { validator: validateTimeRange, trigger: 'change' }
  ],
  endTime: [
    { required: true, message: '请选择结束时间', trigger: 'change' },
    { validator: validateTimeRange, trigger: 'change' },
    { validator: validateEndTime, trigger: 'change' }
  ]
}
```

### 4. 禁用过去时间 ✅

**开始时间禁用逻辑**:
```javascript
const disabledStartHours = () => {
  const now = new Date()
  const currentHour = now.getHours()
  const today = now.toDateString()
  const selectedDate = bookingForm.value.date ? 
    new Date(bookingForm.value.date).toDateString() : today
  
  const disabled = []
  
  // 禁用 8 点之前和 19 点之后的小时
  for (let i = 0; i < OPEN_HOUR; i++) disabled.push(i)
  for (let i = CLOSE_HOUR; i < 24; i++) disabled.push(i)
  
  // 如果选择的是今天，禁用当前小时之前的时间
  if (selectedDate === today) {
    for (let i = OPEN_HOUR; i < currentHour && i < CLOSE_HOUR; i++) {
      if (!disabled.includes(i)) disabled.push(i)
    }
  }
  
  return disabled
}
```

### 5. 快捷选项 ✅

**快捷按钮**:
- **30 分钟后**: 当前时间 + 30 分钟（15 分钟间隔，不超过 19:00）
- **1 小时后**: 当前时间 + 1 小时（15 分钟间隔）
- **明天 9:00**: 明天上午 9 点整
