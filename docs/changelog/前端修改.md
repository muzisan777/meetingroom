## 技术细节

### 今日预约过滤逻辑
```javascript
const todayBookings = computed(() => {
  const today = dayjs().format('YYYY-MM-DD')
  
  return allBookings.value
    .filter(b => {
      const bookingDate = dayjs(b.start_time).format('YYYY-MM-DD')
      return bookingDate === today && b.status !== 'cancelled'
    })
    // ... 关联会议室和用户信息
})
```

### 状态显示逻辑
- **待开始**: 当前时间 < 预约开始时间
- **使用中**: 开始时间 ≤ 当前时间 ≤ 结束时间
- **已完成**: 当前时间 > 预约结束时间
