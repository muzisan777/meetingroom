# 时间选择器优化 - 下拉选择框

## 修改时间
2026-03-13 23:06

## 修改内容

### 更换为下拉选择框 ✅

**修改前**: 使用时间选择器（el-time-picker）
- 需要点击多次选择小时和分钟
- 不够直观

**修改后**: 使用下拉选择框（el-select）
- 一次性显示所有可用时间段
- 灰色显示不可选时间
- 更直观、更快捷

### 时间范围：8:00-19:00 ✅

**可用时间段**:
- **8 点**: 8:30, 8:45
- **9-18 点**: 每个小时的 00, 15, 30, 45 分
- **19 点**: 19:00

**总共 46 个时间段**:
```
8:30, 8:45
9:00, 9:15, 9:30, 9:45
10:00, 10:15, 10:30, 10:45
11:00, 11:15, 11:30, 11:45
12:00, 12:15, 12:30, 12:45
13:00, 13:15, 13:30, 13:45
14:00, 14:15, 14:30, 14:45
15:00, 15:15, 15:30, 15:45
16:00, 16:15, 16:30, 16:45
17:00, 17:15, 17:30, 17:45
18:00, 18:15, 18:30, 18:45
19:00
```

### 智能禁用逻辑 ✅

**选择今天**:
- 当前时间之前的时间段显示为灰色（不可选）
- 例如：当前 10:25，则 8:30-10:15 都显示为灰色

**选择明天及以后**:
- 所有时间段都可选（无灰色）

**结束时间**:
- 自动禁用小于等于开始时间的选项
- 例如：开始时间选 10:00，结束时间的 8:30-10:00 都显示为灰色

### 代码实现

**时间选项生成**:
```javascript
const availableTimeSlots = computed(() => {
  const slots = []
  const now = new Date()
  const today = now.toDateString()
  const selectedDate = bookingForm.value.date ? 
    new Date(bookingForm.value.date).toDateString() : today
  
  for (let hour = 8; hour <= 19; hour++) {
    // 8 点只有 30,45 分；19 点只有 0 分；其他小时有 0,15,30,45 分
    const minutes = hour === 8 ? [30, 45] : (hour === 19 ? [0] : [0, 15, 30, 45])
    
    for (const minute of minutes) {
      const value = `${String(hour).padStart(2, '0')}:${String(minute).padStart(2, '0')}`
      const label = value
      
      // 如果选择的是今天，检查是否小于当前时间
      let disabled = false
      if (selectedDate === today) {
        const slotTime = new Date()
        slotTime.setHours(hour, minute, 0, 0)
        if (slotTime < now) {
          disabled = true
        }
      }
      
      slots.push({ value, label, disabled })
    }
  }
  
  return slots
})
```

**模板**:
```vue
<el-form-item label="开始时间" prop="startTime">
  <el-select v-model="bookingForm.startTime" placeholder="请选择开始时间">
    <el-option
      v-for="slot in availableTimeSlots"
      :key="slot.value"
      :label="slot.label"
      :value="slot.value"
      :disabled="slot.disabled"
    />
  </el-select>
</el-form-item>

<el-form-item label="结束时间" prop="endTime">
  <el-select v-model="bookingForm.endTime" placeholder="请选择结束时间">
    <el-option
      v-for="slot in availableTimeSlots"
      :key="slot.value"
      :label="slot.label"
      :value="slot.value"
      :disabled="slot.disabled || slot.value <= bookingForm.startTime"
    />
  </el-select>
</el-form-item>
```

## 优势

1. **更直观**: 一眼看到所有可用时间段
2. **更快捷**: 一次点击即可选择，无需多次操作
3. **更清晰**: 灰色显示不可选时间，一目了然
4. **更智能**: 自动禁用过去时间和不符合逻辑的时间
